LM STUDIO Pre-Wedding Website
=============================

ဖိုင်များ
- index.html   : Website (ဒါကို ဖွင့်ကြည့်ပါ)
- admin.html   : ပြင်ဆင်ရန် Editor (စာ၊ ပုံ၊ Gallery၊ ဆောင်းပါး၊ link များ)
- content.js   : စာနဲ့ ပုံစာရင်း အားလုံး (admin.html က ဒီဖိုင်ကို ပြင်ပေးပါတယ်)
- img/         : ပုံများ
- backups/     : Save နှိပ်တိုင်း content.js အဟောင်းကို ဒီထဲ သိမ်းထားမယ်

ပြင်နည်း (အကျဉ်း)
1. Zip ကို Extract လုပ်ပါ။
2. admin.html ကို Google Chrome / Microsoft Edge နဲ့ ဖွင့်ပါ။
3. အပေါ်က "Folder ချိတ်ရန်" နှိပ် → ဒီ folder ကို ရွေး → Allow / Edit files ခွင့်ပြုပါ။
4. ဘယ်ဘက် tab တွေကနေ ပြင်ပါ။ ညာဘက်မှာ ချက်ချင်း မြင်ရပါမယ်။
5. "သိမ်းရန် (Save)" (သို့မဟုတ် Ctrl+S) နှိပ်ပါ။
6. index.html ကို Refresh လုပ်ကြည့်ပါ။

Firefox/Safari သုံးရင်: ပြင်ပြီး "content.js ဒေါင်းရန်" နှိပ် → ဒေါင်းလာတဲ့ content.js နဲ့ folder ထဲက အဟောင်းကို အစားထိုးပါ။

Hosting ပေါ်တင်ရင်: index.html, content.js, img/ ကို upload တင်ပါ (admin.html မလိုပါ)။
